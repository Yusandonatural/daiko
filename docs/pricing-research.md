# 草刈り作業単価 相場調査メモ（2026年9月調べ）

サイトの標準料金（`config.js` の `pricing`）を決めるための調査結果です。

## 1. 宅地・空き地系（造園業者・便利屋など）

| 指標 | 相場 | 備考 |
|---|---|---|
| ㎡単価 | 100〜300円/㎡（草丈が高いと〜500円） | 草丈が低く広い土地は 80〜150円/㎡ |
| 坪単価 | 500円/坪〜（大阪の格安業者） | 税込550円/坪 |
| 30坪（約100㎡） | 8,000〜30,000円 | |
| 100坪（約330㎡） | 25,000〜60,000円 | |
| 時間単価 | 3,000〜5,000円/時間（業者） | |

料金が変動する要因：草丈・密度、地形の起伏、刈草処分の有無、依頼先の種類。
同じ50坪でもシルバー人材センター約1万円 vs 造園業者3万円超と数倍の差が出る。

## 2. シルバー人材センター

| 指標 | 相場 |
|---|---|
| 時間単価 | 1,000〜2,000円/時間（例：世田谷区 1,469円、機械草刈 1,557円/時間） |
| ㎡単価 | 100〜300円/㎡ |
| 追加費 | 処分費・事務費・機械使用料・運搬費が別途の場合あり |

安価だが、繁忙期は数週間待ち、機械作業の制限あり。

## 3. 農地（休耕田・畦畔）の作業受託

| 指標 | 相場 | 出典の種類 |
|---|---|---|
| 休耕田 10a（1反）全体 | 1万円台前半〜4万円前後 | 民間受託業者 |
| 休耕田 10a | 11,000円（広島県東広島市の公開料金例） | 民間 |
| 休耕田 10a | 19,800円（税込）の受託例 | 民間 |
| 畦草刈り | 約4,300円/100m | 福井県農業会議 令和8年版 農作業標準料金 |
| 畦畔草刈り（時間制） | 1,350円/時間 + 事務費1,500円 | 湯前町農業公社 |
| 畦の時間単価 | 1,800〜2,500円/時間 | 民間 |
| 草丈50cm以上 | 2割増 | 国東市農業公社の料金表 |

農作業標準料金は「受委託契約の目安」として各自治体の農業委員会・農業会議が毎年定めており、地形・ほ場条件を勘案して当事者間で決める建前。

## 4. サイトに採用した標準料金（案）

| 項目 | 採用値 | 根拠 |
|---|---|---|
| 田畑・休耕地 | 15,000円/10a（=150円/㎡） | 農地受託相場（1万円台前半〜4万円）の下寄り。地元農家の副業として価格競争力を持たせる |
| 宅地・空き地 | 200円/㎡ | 業者相場 100〜300円の中央値 |
| 畦畔・法面 | 4,000円/100m | 農業会議標準 4,300円/100m に準拠 |
| 時間制 | 2,500円/時間・人 | 民間畦畔相場の上限、シルバーより高く業者より安い |
| 草丈50cm〜1m | +20% | 農業公社料金表の慣行 |
| 集草・搬出 | +50円/㎡ + 処分実費 | 処分費別途が業界慣行 |
| 出張費 | 15km以内無料、15〜30km 2,000円 | 30km圏内設定に合わせた独自設定 |
| 最低料金 | 8,000円 | 30坪相場の下限 |
| 年間契約 | 10%割引 | 独自設定 |

**注意：** 上記は調査に基づく提案値です。燃料費、移動時間、実作業時間を踏まえ、`config.js` で調整してください。
目安として、刈払機での平地作業は 1人 1時間あたり 300〜500㎡ 程度が進む想定です（10a ≒ 2〜3時間）。
