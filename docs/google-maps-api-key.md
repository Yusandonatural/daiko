# Google Maps API キーの取得手順

キーがなくてもサイトの地図は OpenStreetMap でピンと 30km の円を表示します。
Google Maps の見た目にしたい場合だけ、以下の手順でキーを取得して `config.js` の `googleMapsApiKey` に貼り付けてください。

## 費用について

- Google Maps Platform は請求先（クレジットカード）の登録が必須です
- Maps JavaScript API は月 10,000 回の読み込みまで無料枠があり、このサイトの規模なら通常は無料に収まります
- 念のため「予算アラート」を設定しておくと安心です

## 手順（10分程度）

1. [Google Cloud Console](https://console.cloud.google.com/) に Google アカウントでログイン
2. 画面上部のプロジェクト選択 →「新しいプロジェクト」→ 名前「daiko-map」など → 作成
3. 左メニュー「お支払い」→ 請求先アカウントを作成（カード登録）→ プロジェクトに紐付け
4. 左メニュー「API とサービス」→「ライブラリ」→「Maps JavaScript API」を検索 →「有効にする」
5. 「API とサービス」→「認証情報」→「認証情報を作成」→「API キー」
6. 作成されたキーの「キーを編集」を開き、次のように制限を設定
   - **アプリケーションの制限**：「ウェブサイト」
   - **ウェブサイトの制限**：公開 URL を追加（例：`https://yusandonatural.github.io/*`、独自ドメインなら `https://example.com/*`）
     ローカル確認用に `http://localhost:*/*` も追加しておくと便利
   - **API の制限**：「キーを制限」→「Maps JavaScript API」のみチェック
7. 「保存」→ キーの文字列（`AIza...`）をコピー
8. `config.js` を開き、`googleMapsApiKey: ""` の引用符の中に貼り付けて保存・コミット

## 確認

サイトを開いて「対応エリア」の地図が Google Maps の見た目（薄い灰色の地図、Google ロゴ）になっていれば完了です。
キーが無効な場合や制限に引っかかる場合は自動で OpenStreetMap に戻ります。

## 注意

- キーは `config.js` に平文で入るため、必ず「ウェブサイトの制限」を設定してください。これで他サイトからの不正利用を防げます
- キーは Git にコミットされて公開されます。ウェブサイト制限を設定済みなら公開して問題ありません（Google の想定どおりの使い方です）
