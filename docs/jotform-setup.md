# Jotform 受付フォームの作り方

サイトの「お申し込み」欄には Jotform のフォームを埋め込みます。
`config.js` の `jotformFormId` にフォーム ID を入れるだけで表示が切り替わります。

## 1. フォームを作る

1. [Jotform](https://www.jotform.com/) にログイン →「フォームを作成」→「白紙から作成」→「クラシックフォーム」（1ページに全項目）
2. 下記の項目を追加（左メニュー「フォーム要素」からドラッグ）
3. 「公開」→「埋め込み」→「iFrame」を開き、URL `https://form.jotform.com/251234567890123` の数字部分をコピー
4. `config.js` の `jotformFormId: "251234567890123"` に貼り付け

## 3. おすすめ設定

- **設定 → メール**：「通知メール」に受付用アドレス、「自動返信メール」でお客様に受付完了を送る
- **設定 → フォーム設定**：「送信後のサンクスページ」に「2〜3日以内にご連絡します」と記載
- **設定 → 連携**：Google スプレッドシート連携を入れると依頼一覧を自動で管理できます
- **フォームデザイン**：サイトの配色に合わせる場合、ボタン色 `#b7793d`、見出し色 `#1f3d2b`
- 無料プランは月 100 件・容量 100MB まで。写真添付が多い場合はプラン変更を検討

## 4. 表示を確認する

`config.js` に ID を入れた状態でサイトを開き、「お申し込み」欄に Jotform のフォームが出れば完了です。
簡易フォーム（メーラー起動）は自動で非表示になります。
