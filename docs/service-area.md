# 対応エリア（30km圏内）の算出

太子町役場（北緯 34.518682、東経 135.647661）から半径 30km の円に区域が含まれる市町村の一覧です。

## 算出方法

- 境界データ：国土数値情報 行政区域データ N03（2020年1月1日時点）を GeoJSON 化した [niiyz/JapanCityGeoJson](https://github.com/niiyz/JapanCityGeoJson) を使用
- 太子町役場から各市町村の境界線までの **最短距離**（役場が区域内なら 0）と **最遠距離** を計算
- 最短距離 ≤ 30km を「圏内に含まれる」、最遠距離 ≤ 30km を「全域」、それ以外を「一部」と分類
- 政令指定都市（大阪市・堺市）は区をまとめて市単位で扱う
- 距離は役場を原点とした正距円筒近似（半径 30km では誤差 0.1km 未満）

**結果：74 市町村（全域 44、一部 30）**

## 更新するには

`assets/areas.js` を編集すると、サイトの一覧と申し込みフォームのドロップダウンが自動で更新されます。
Jotform 側のドロップダウンは別管理なので、変更時は `docs/jotform-setup.md` の市町村リストを貼り直してください。
中心地点や半径を変える場合は `config.js` の `center` / `radiusKm` を変更したうえで、上記の方法で一覧を再計算してください。
